# 药敏板智能判读 Demo（96 孔微量肉汤稀释板）

对应《药敏板判读系统-技术方案》Phase 0/1 的最小可运行版本：上传照片 → 判读 MIC → 复核表格 → 导出 Excel。

## 文件说明

| 文件 | 作用 |
|---|---|
| `generate_samples.py` | 生成模拟药敏板照片 + 真实值（没有真实照片时用来验证算法） |
| `ast_reader.py` | 判读管线：板检测 → 透视校正 → 孔位定位 → 颜色提取 → 对照孔校准判读 → MIC 推导 → 标注图/JSON/Excel |
| `verify.py` | 批量跑判读并与真实值比对，输出准确率 |
| `app.py` | Web Demo（FastAPI + 单页前端：单张/多张上传 → 判读 → 表格 → 导出 Excel） |
| `probe_photo.py` | 单张照片判读条件体检（板检测/孔位校准/分色/判读矩阵） |
| `templates/chromogenic_plate.json` | 真菌药敏板（显色法）模板（行式布局 + 说明书规则） |
| `templates/dryplate_a.json` | 真菌微量肉汤干板 A板 模板（无显色剂，读生长） |
| `templates/dryplate_b.json` | 真菌微量肉汤干板 B板 模板（上/下半区，可为两个菌株） |
| `probe_growth.py` / `probe_color.py` | 调参探针：打印逐孔生长度量 / 颜色矩阵（排查用） |
| `judge_plates.py` | 命令行批量判读（指定模板 + 多张照片） |
| `qc_rules.json` | 质控范围配置（目前含 6258 克柔假丝酵母菌 24H/48H CLSI 范围） |
| `template.json` | 板型模板：药物列、浓度、对照孔、空位。**换新板型改这里即可** |
| `samples/` | 模拟照片与真实值 |
| `outputs/` | 判读输出：标注图、矫正图、Excel |

## 快速开始

```bash
cd ast-demo

# 1. 生成模拟照片
uv run --with opencv-python --with numpy python generate_samples.py

# 2. 验证判读准确率（对比真实值）
uv run --with opencv-python --with numpy --with openpyxl --with pillow python verify.py

# 3. 启动 Web Demo
uv run --with fastapi --with uvicorn --with opencv-python --with numpy --with openpyxl --with pillow --with python-multipart python app.py
```

浏览器打开 http://127.0.0.1:8765 ，上传自己的照片（手机上会直接调起相机）。

Windows 上也可以直接双击启动脚本：`启动判读系统.bat`（仅本机访问）或 `启动判读系统-局域网.bat`（开放给内网，手机/其它电脑用窗口里显示的 IP 地址访问；首次运行如弹防火墙提示，勾选「专用网络」并允许）。

## 用真实照片测

1. 点击「上传药敏板照片」，选择照片
2. 拍摄建议：板子水平、占画面主体、光线均匀、背景与板子反差明显
3. 判读结果仅供参考，务必人工复核（黄色标注的孔和「跳跃孔」警告尤其要看）

> 仓库不含真实药敏板照片（临床信息敏感）。本机 `samples/real_XX.jpg` 仅用于命令行与接口测试（页面已不内置示例按钮）；`samples/sample_01~03.jpg` 是软件生成的合成测试图，随仓库提供。

## 自定义板型

编辑 `template.json`：

- `drugs`：列号 → 药物代码/名称/浓度（A→H 从高到低）
- `detection.positive_control` / `negative_control`：对照孔位置（判读的颜色基准）
- `unused_cols`：不使用（空置）的列

## 多张照片（同一菌株）

- 上传时一次可多选照片（手机相册/文件多选）；网页会把它们按「同一菌株」合并处理。
- **每张照片独立判读**，各自用自己板上的对照孔校准，所以多张照片的拍摄条件可以不同。
- 结果自动合并成一张总表：
  - 同一药物、多张照片结果一致 → 合并为一行，列出全部来源照片；
  - 结果不一致 → 分行标红「多图结果不一致」，提醒人工复核。
- **每张照片的明细里都带自己的逐孔板面**：点击孔位复核后，该照片的 MIC 自动重算，合并表同步更新（顶部板面 = 第 1 张照片，也可直接点击复核）。
- 导出的 Excel：`MIC汇总(合并)`（含来源照片列）+ `逐孔明细`（全部照片，带来源照片列）。

## 判读条件

**拍摄条件**

- 板子完整入镜、占画面主体；允许一定倾斜（软件自动做透视校正）。
- 光照均匀即可，透射光（灯箱/光台）或普通光照都可以；避免强反光、阴影遮挡孔面。
- 照片不能明显模糊；软件会做清晰度检查并提示重拍。

**板型配置条件（决定药物名和 MIC 是否有实际意义）**

- 需要按真实板型配置 `template.json`：每列是什么药、浓度梯度方向、对照孔位置、空置孔、指示剂类型（如刃天青蓝→粉红颜色变化）。
- 演示模板只是示例配置；换成真实板型前，药物名/浓度为占位值。

**算法判定条件**

- 孔位自动校准：直接从照片拟合孔位网格（自相关测孔距 + 相位对齐），不要求板子边距完全符合标准。
- 判「生长/无生长」：默认以对照孔（阴性/阳性）为基准计算颜色距离；对照孔缺失、颜色过近或与模板设定相反时，自动改用绝对颜色阈值判读并给出提示。
- 每个孔输出置信度；沿浓度出现「跳跃孔」时自动标记，提醒人工复核。
- MIC = 沿浓度梯度第一个判为「无生长」的孔（`≤最低浓度` / `>最高浓度` 表示超出梯度范围）。

## 真菌药敏板（显色法）

真实板型模板：`templates/chromogenic_plate.json`（依据产品说明书）。

**板型布局（行式排列）**

- 第 1 列 A1-H1：两性霉素B（16→0.12 µg/mL）
- 每行一种药（从第 2 列起浓度自高到低）：A 行=氟胞嘧啶、B 行=米卡芬净、C 行=卡泊芬净、D 行=氟康唑、E 行=艾莎康唑、F 行=伏立康唑、G 行=泊沙康唑、H 行=伊曲康唑
- A12=阳性对照孔（须出现粉红色方可判读）、H12=阴性对照孔（应无生长）

**判读规则（按说明书实现）**

- MIC = 无生长孔中抗真菌药物浓度最低者
- 紫色：两性霉素B 按生长计；其他药物按无生长计
- 跳孔：1 个忽略并提示；≥2 个结果无效、提示重做
- 只读取颜色变化，不读取浊度
- 阳性对照未变粉红 → 提示延长培养/查找原因

**使用**

- 网页：把「板型模板」切换为「真菌药敏板（显色法）」，再上传照片（支持一次多张，同一菌株合并）。
- 命令行：`uv run --with opencv-python --with numpy --with openpyxl --with pillow python judge_plates.py templates/chromogenic_plate.json <照片...>`

暂未实现：曲霉属 MEC 判读、隐球菌 48–72h 特殊规则、S/I/R 折点判定。

**记录与复核流程（网页）**

- 先填基本信息：**菌属（念珠菌属 / 曲霉属，颜色判读规则不同）**、菌种、样本编号、培养信息（如 1640(Tris)）、时间点（24H/48H/72H）、实验批次、操作人。
- **菌属判读规则**（页面「当前判读条件」实时提示，规则可在模板中修改）：
  - 念珠菌属：粉红/红色＝阳性（生长），蓝色或紫色＝阴性（抑制）；两性霉素B 的紫色/粉色/红色均按阳性。
  - 曲霉属：康唑类（FLU/ISA/VRC/POS/ITR）紫色或粉色＝阳性；其余同念珠菌属。
- 「板面」区自带上传按钮，也可把照片**拖入**；上传后**原图与逐孔板面并排显示**，方便对照复核。
- **照片本身可点击复核**：直接点标注照片上的孔位（悬停高亮）即可切换状态；「查看原图」可在新标签页打开未标注的原始照片。
- **逐孔板面可点击**：点击任意孔位循环切换 生长→抑制→临界，**MIC 值与质控会自动重算**；也可在 MIC 表中用下拉框直接修改，勾选「已人工复核」后导出。
- 每次判读会记入「本次会话记录」列表，点击可重新查看。
- **板面与判读条件可上传/下载**：下载当前模板 JSON → 修改药物/浓度/对照孔/genus_rules 颜色规则 → 上传即生效。
- 导出 Excel：
  - `MIC报告`（简洁长表）：菌株编号/菌属/菌种/培养信息/时间点/实验批次/操作人/照片/药物/药物名称/**MIC**/复核/质控/备注，**每药一行**；
  - `MIC登记表`：药物列仅用代码；顶部带 24h/48h 质控范围行（样本编号含 6258 自动带出），**每张照片一行**，超范围标红；
  - `复核明细`（软件建议 ↔ 复核值）与 `逐孔明细`（全部孔位）。

## 真菌微量肉汤干板（A板 / B板）

真实板型模板：`templates/dryplate_a.json`、`templates/dryplate_b.json`（按板面版式表配置）。

**与显色板的区别**：干板无显色剂，只读生长（均匀浑浊或点状菌落）；判读标准参考 CLSI M27 微量肉汤稀释法：生长量 ≥ 阳性对照的 50% 计为生长。

**算法（两种生长形态都覆盖）**

- 浊度度量：孔内比孔周围板面暗的程度（均匀浑浊型生长）；
- 暗点占比：孔内细小暗点像素占比（点状菌落型生长）；
- 两者分别相对阳性对照归一化，任一 ≥50% 判为生长；网格自动校准为「自相关曲线 + Hough 圆检测」双通道择优，逐孔中心带防误吸保护；跳孔规则同显色板（1 个忽略、≥2 个无效）。

**A板**（FMIC 对照 A 板面）：A 行卡泊芬净、B 行米卡芬净、C 行阿尼芬净、D 行瑞扎芬净（均 12 孔）、E 行两性霉素B（E1–E8）、F 行艾莎康唑（F1–F11）、G 行泊沙康唑（G1–G11）；阳性对照 E9–E12、F12、G12，阴性对照 H12（H 行其余为空孔，自动忽略）。

**B板**（FMIC 对照 B 板面）：上半区 A 行伊曲康唑、B 行伏立康唑、C 行氟康唑、D 行氟胞嘧啶；下半区 E–H 行同布局（代码带 `-2` 后缀：ITR-2/VRC-2/FLU-2/FCT-2）。阳性对照 A12、D12、E12、H12。**上下半区有时接种两个菌株**（同一块板做两块实验）——此时填「下半区菌号」，导出 Excel 时下排药物自动标注下半区菌号。

**使用**：把模板下拉切到对应干板（A板/B板）后上传照片。

命令行：`uv run --with opencv-python --with numpy --with openpyxl --with pillow python judge_plates.py templates/dryplate_a.json <照片...>`

## 链球菌微量肉汤板（A / B / C 版）

真实板型模板：`templates/strep_a.json`、`strep_b.json`、`strep_c.json`（链球菌微量肉汤稀释板，标准 96 孔 8×12）。

- **A版**：阿莫西林/克拉维酸（A1–A10）、氨苄西林（B1–B9）、阿莫西林（C1–C10）、氯霉素（D1–D5）+ 克林霉素（D6–D12）、头孢曲松（E1–E9）、头孢噻肟（F1–F9）、头孢呋辛（G1–G5）、红霉素（H1–H9）
- **B版**：头孢吡肟（A1–A9）+ 亚胺培南/西司他丁（A10）、利奈唑胺（B1–B6）、左氧氟沙星（C1–C6）、美罗培南（D1–D8）、莫西沙星（E1–E8）、新霉素（F1–F8）、青霉素（G1–G9）、利福平（H1–H10）
- **C版**：复方磺胺甲噁唑（A1–A8）、四环素（B1–B9）、替考拉宁（C1–C8）、替加环素（D1–D8）、万古霉素（E1–E8）

阳性对照 A12、阴性对照 H12；浓度自左向右递减，空孔自动忽略。**判读按说明书（比色/比浊法）**：药敏孔出现浑浊/沉淀即判为生长，澄清为无生长；以生长对照 C+ 为基准，C+ 未生长时结果不可信；药敏孔不读取颜色；SXT 拖尾/微弱生长判为阴性。

判读算法使用链球菌专用 `growth_metric: "pellet"`：先看**孔中心暗点（沉淀/菌膜）与孔内环的亮度对比**，再看**环形区暗像素比例**（弥散浑浊/晕圈）。这样可以排除孔底反光、气泡和中心点的干扰。已用真实链球菌 A 板照片（092-A）验证：与人工复核 **75/75 孔一致（100%）**，9 个药物 MIC 全部一致；该图 C+ 与 C− 均生长，软件正确提示“阴性对照孔 H12 出现生长迹象，可能存在污染，结果不可信”。网页：模板下拉选择对应版本后上传照片。

## 训练闭环：评估与调参

- **评估**：用网页导出的「复核数据（训练用 CSV）」评估软件判读质量：
  `uv run --with opencv-python --with numpy python evaluate_training.py templates/dryplate_a.json 复核数据1.csv ...`
  输出孔级一致率、MIC 完全一致率、EA（≤1 个稀释度）和主要差异明细，并生成 `outputs/训练评估报告.md`。
- **模板内可调参数**（改 JSON 后上传即可生效）：
  - `detection.growth_rule`：`50_percent`（真菌干板，默认）或 `visible`（细菌板：出现可见浑浊/沉淀即判生长）
  - `detection.growth_metric`：`pellet`（链球菌板：中心沉淀/菌膜 + 环形区浑浊）或省略（通用浊度度量）
  - `detection.pellet_thresholds`：链球菌 pellet 度量的阈值（`min_contrast` / `min_halo_dark` / `no_growth_contrast` / `no_growth_halo_dark`）
  - `detection.absolute_fallback`：低对比度/整板浑浊时的绝对亮度兜底（链球菌模板已开启）
  - `detection.growth_thresholds`：生长判定阈值（`visible` 默认 0.2/0.1；`50_percent` 默认 0.5/0.3，相对阳性对照）
  - `detection.drug_growth_thresholds`：单药阈值覆盖（如 SXT 拖尾：`growth_min` 0.5、`no_growth_max` 0.2）
  - `detection.trailing_codes`：拖尾药物代码（如 `["SXT"]`），临界孔按无生长处理
  - `detection.partial_policy`：临界孔如何参与 MIC 推导（`no_growth` 默认 / `growth`）
  - 显色板：`detection.color_thresholds` + `color_rules`（见「颜色分级与判读模型标定」）
- 已用 8 组复核数据（约 150 张照片/结果图、7500+ 孔）评估：孔级一致率 93.8%–100%，EA 83.9%–98.2%。
  显色板与 150 板结果图接近满分；干板差异集中在 MIC 边界 ±1 稀释度的拖尾生长判断，建议结合界面上的「临界/跳孔」提示人工复核。

## 打包成 Windows exe（可选）

已用 PyInstaller 打包为单文件程序：`dist/AST-Plate-Reader.exe`（约 80MB，目标电脑无需安装 Python）。

- 双击运行：自动打开浏览器 `http://127.0.0.1:8765`（黑色控制台窗口即服务进程，关闭窗口即停止）。
- 换端口 / 开放内网：设置环境变量 `AST_PORT`、`AST_HOST`（`0.0.0.0` 为内网可访问）。
- 数据位置：原图、导出、自定义模板保存在 exe 同目录的 `outputs/`、`templates/`。
- 重新打包命令：
  `uv run --with pyinstaller --with fastapi --with uvicorn --with opencv-python --with numpy --with openpyxl --with pillow --with python-multipart python -m PyInstaller --noconfirm --clean --onefile --name AST-Plate-Reader --add-data "templates;templates" --add-data "template.json;." --add-data "qc_rules.json;." --hidden-import uvicorn.logging --hidden-import uvicorn.loops.auto --hidden-import uvicorn.protocols.http.auto --hidden-import uvicorn.protocols.websockets.auto --hidden-import uvicorn.lifespan.on app.py`
- 注意：个别杀毒软件可能对 PyInstaller 程序误报，需加白名单；同一时间只能运行一个实例（端口冲突）。

## 颜色分级与判读模型标定（显色法）

指示剂颜色随生长推进：**蓝（无生长）→ 紫（临界）→ 粉红（生长）→ 粉白（生长）→ 白（生长）**。

- 软件对每个孔记录 色相H / 饱和度S / 明度V 与颜色分级；**逐孔板面里的小圆点显示该孔颜色**（鼠标悬停可看颜色名称）。
- 阈值写在模板 `detection.color_thresholds`（`white_max_s` / `pink_min_s` / `purple_h` / `blue_h`），`detection.color_rules` 定义每种颜色对应的判读状态，可按实验室习惯调整。
- **用人工复核数据训练/标定颜色模型**：
  1. 网页上完成复核（点照片孔位或逐孔板面切换），点「导出复核数据（训练用 CSV）」；
  2. 运行 `uv run python fit_color_model.py 复核数据_训练用.csv templates/chromogenic_plate.json`；
  3. 得到 `learned_color_thresholds.json`，把 `detection.color_thresholds` 粘进模板后用页面「上传模板」立即生效。
- 这是"阈值标定"式的轻量学习：可解释、需要数据少；等复核数据积累多了（几百孔以上）再考虑统计/深度模型。

## 不会写 JSON 怎么办？

模板 JSON 只用于技术微调，**正常使用不需要自己写**：把板面版式表（照片/表格）发来即可，由软件侧把模板配好内置。已有板型可在页面「下载模板 JSON」查看格式，改药名/浓度后再「上传模板」即可生效。
