# AST-Plate-Reader 品牌标识

## 设计思路

不画显微镜、不画十字、不画 DNA —— 那些是「医疗」的通用陈词。
这个产品真正做的事只有一件：**在一张 96 孔药敏板上，把「由生长转为不生长」的那一孔找出来，读成 MIC。**

所以符号直接把这件事画了出来：

- **牌底**：外圈凸边 + 内嵌板面，还原真实微孔板的双层结构（不是随便一个圆角矩形）。
- **孔距**：正方形孔距，对应真板 9 mm 等距，远看就是一张板而不是一串点。
- **梯度**：孔位由「空圈」渐变到「实心」，就是药物浓度的连续稀释。
- **判定圈**：一个绿色圆环落在交界那一孔。这个绿 `#1A7F37` 不是随便挑的 ——
  它就是软件界面里给 MIC 判定孔画的那道圈，符号与产品 UI 同源，看惯界面的人一眼认得。

一句话：**别人画的图标是「医疗器械」，这个图标是「一次判读」。**

## 两个方案

| 方案 | 说明 | 适用 |
|---|---|---|
| **hero**（主推） | 全板走中性灰，只让中间一行上色。一行 = 一个药物的浓度梯度，正是判读动作本身 | 默认用这个 |
| grid（备选） | 整版孔位同等权重，每行都有判定圈 | 需要「整板/高通量」叙事时 |

hero 的好处是小尺寸下不掉细节：缩到 32px，眼睛看到的是「板 + 一条彩线 + 一个绿点」，信息没丢；
grid 缩到 32px 会糊成一格一格的纹理。

## 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主深色（牌底） | `#0A171C` → `#14323C` | 竖向渐变，深墨青，比纯黑耐看，压得住白牌 |
| 板面白 | `#FCFEFF` | 略带冷调，避免死白 |
| 凸边 | `#E2ECF0` | 与板面拉开 1 级，形成「边缘」 |
| 空孔圈 | `#B0C6CE` | 未生长 |
| 生长渐变 | `#F0B0C2` → `#920E3A` | 浅到深 = 浓度由低到高，取自界面「阳」的红系 |
| 判定圈绿 | `#1A7F37` | 与界面 MIC 判定孔完全一致 |
| 单色版 | 灰阶 `#C6D6DC` → `#122E38` | 印刷、传真、单色屏、烫印 |

## 使用规则

- 方形图标最小 **24 px**；≤ 32 px 时只用 hero 方案，别用 grid。
- 图标四周留白 ≥ 图标边长的 **1/8**，不要把牌底裁到边。
- 横版组合最小宽度 **220 px**；更窄时只用方形图标，不要带字。
- 深色背景一律用 `-dark` 或去背板版；浅色背景用主版。**不要**给深色底强行贴白底方图。
- 不要把牌子歪着放、不要加投影以外的特效、不要改判定圈的颜色。

## 重新生成

```bash
cd brand
PYTHONPATH="$(cygpath -w "$PWD/../.venv-ast/site-packages")" \
  C:/Python314/python.exe gen_logo.py
```

依赖：Pillow（已在 `../.venv-ast` 里）。字体取系统自带的 Bahnschrift（字标）、
Segoe UI Semibold（副行）、Microsoft YaHei（中文），无需额外装字体。
